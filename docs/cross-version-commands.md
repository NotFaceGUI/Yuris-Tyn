# 跨版本命令名对照表（P0）

> 本表是**命令名 ↔ 引擎序号**的唯一权威对照，供 `VersionProfile` 运行期分派使用。
> 生成器：`scripts/probe_cross_version.py`（可复现）。

## 1. 数据来源与证据等级

| 版本 | 来源 | 引擎/YSCM version | 命令数 | 证据等级 |
|---|---|---|---|---|
| **555** | `docs/opcode/yscm-commands-555.json`（运行期 `ysc.ybn`） | 555 | 121 | **Confirmed** |
| **494** | `docs/opcode/yscm-commands-494.json`（运行期 `ysc.ybn`，实测抽取） | 494 | 119 | **Confirmed** |
| **495** | SDK 0.495 编译器侧 `YSCom.ycd`（证据源） | 495 | 119 | Likely（编译器侧命令表；与 v494 运行期表逐条同序，见 §3） |
| **479** | SDK 0.479 编译器侧 `YSCom.ycd`（证据源） | 479 | 104 | Likely |

**关键结论**：494（运行期 YSCM）与 495（SDK 编译器侧命令表）命令名列表**逐条同序完全相同** ——
说明 SDK 编译器命令序 == 运行期 YSCM 序，编译器侧表可作运行期表的等价证据。

## 4. SDK 0.495 分发表（证据侧，供 555 侧定位对照）

- 基址 `0x7ace20`，共 92 个显式覆盖槽（其余槽走默认处理函数）。
- 约定：**槽位下标 = YSCM 命令下标本身**（无偏移）。
  见 SDK 逆向文档 `docs/format-vm-opcodes.md` §1。
- 555 侧约定不同：处理器表 `0x78b020` 共 121 项，**运行期表索引 = YSCM 下标 + 8**
  （12+ 锚点吻合，见本仓库 `PROGRESS.md` 成果 30）。

> ⚠️ 上面这条「+8 vs 无偏移」的差异本身就是跨版本差异的实证：
> **分派只能来自游戏自己的 ysc 表，不能来自任何硬编码常量表。**
